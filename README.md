# fish

Build more pages with less CSS code.

## Use

### By CDN

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/AkaraChen/fish@latest/fish.css">
```

### By bundler

```js
> pnpm add @akrc/fish

import '@akrc/fish/fish.css'
```

## Dev

```shell
pnpm install
pnpm run dev
```

## Build

```shell
pnpm run build
```
